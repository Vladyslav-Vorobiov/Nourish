# Nourish

Nourish is an editorial food magazine built as a frontend portfolio project, exploring seasonal cooking through photography, recipes, and thoughtful kitchen stories.

[Visit Nourish](https://nourish-seven-sigma.vercel.app)

## Features

- A seasonal homepage with recipe selections, a static Pantry Index, and journal previews.
- Three recipe pages with ingredients and step-by-step methods.
- Four editorial guides and articles about seasonal food and everyday cooking.
- Responsive layouts with editorial typography and warm, restrained colors.
- Motion entrances and interactions with reduced-motion support.
- Locally hosted DM Serif Display and DM Sans fonts.
- Per-page Open Graph and Twitter sharing metadata with dedicated photographs.

## Tech stack

Next.js 16 App Router, React, JavaScript/JSX, Tailwind CSS, Motion, and Lucide React. ESLint with the Next.js configuration provides linting; npm and `package-lock.json` manage dependencies.

## Local development

Use Node.js 20.9 or newer and npm. From the project directory:

```sh
npm ci
npm run dev
```

Open [localhost:3000](http://localhost:3000).

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the development server. |
| `npm run lint` | Run ESLint. |
| `npm run build` | Create the production build. |
| `npm run start` | Serve the production build after building. |
